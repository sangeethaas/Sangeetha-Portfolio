## Stack
- HTML / CSS / JavaScript (frontend)
- Node.js / Express (backend API, used for local development)

## Run locally
npm install
cp .env.example .env
npm run dev

## Structure

```text
portfolio/
├── index.html
├── style.css
├── images/
├── js/
│   ├── main.js
│   ├── portfolio.js
│   ├── navigation.js
│   └── catGame.js
└── README.md
```

## Responsibilities

- `index.html` — semantic page structure and static content.
- `style.css` — presentation and responsive layout.
- `js/main.js` — application entry point.
- `js/portfolio.js` — portfolio data and small hydration helpers.
- `js/navigation.js` — navigation behavior and active-section tracking.
- `js/catGame.js` — isolated cat-game feature.
