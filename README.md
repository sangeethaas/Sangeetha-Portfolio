# Sangeetha A S — Portfolio

A backend-focused personal portfolio built as a small Node.js application.

## Current stack
- Node.js
- Express
- REST API
- HTML/CSS

## Run locally
```bash
npm install
cp .env.example .env
npm run dev
```
Open http://localhost:3000

## API
- GET /api/health
- GET /api/profile
- GET /api/projects
